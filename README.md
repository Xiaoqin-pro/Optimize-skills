# Metaheuristic Research Skills

A compact Codex skill set for mechanism-driven research on PSO, CSO, ABC and related swarm/metaheuristic optimization algorithms using MATLAB.

## Included

- pain-first failure-question discovery
- mechanism-level novelty and algebraic-equivalence gate
- MATLAB CEC experiment planning and execution
- CPU/GPU/auto backend policy
- FE-fair statistical analysis
- red-team review and multi-generation outer loop
- CEC2013, 2014, 2017, 2019, 2020 and 2022 ready benchmark folders

Start with [AGENTS.md](AGENTS.md), [RESEARCH_BRIEF.md](RESEARCH_BRIEF.md) and [benchmarks/README.md](benchmarks/README.md).

The MATLAB style follows the local `teacher` project: simple procedural `.m` files, Chinese section comments, explicit optimizer loops and a separate `main.m` orchestration script, while retaining reproducible seeds and explicit FE accounting.
