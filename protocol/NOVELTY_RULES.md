# Novelty Rules

1. Normalize every proposal into state variables, operators, information sources, topology, memory and update equations.
2. Expand equations and test equivalence to inertia schedules, mutation, differential mutation, Lévy perturbation, opposition sampling, random restart, archive guidance and diversity-triggered adaptation.
3. Search by mechanism terms, not only algorithm names.
4. Hybridization passes only when the interaction has a falsifiable causal hypothesis and evidence beyond “A + B”.
5. Use `HOLD` when the closest mechanism is unclear. Do not call an idea novel merely because an exact equation was not found.
6. Record the closest papers and the evidence that could change the verdict.
